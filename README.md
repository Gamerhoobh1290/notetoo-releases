# NoteTOO releases

Official releases of **NoteTOO**, a desktop app for organizing, previewing and annotating school files.
This repository holds the published installers only; NoteTOO's source code is not here.

## Install

Download `NoteTOO-Setup-<version>.exe` from the [latest release](https://github.com/Gamerhoobh1290/notetoo-releases/releases/latest).

## Updates

Install **NoteTOO Updater** (`NoteTOO-Updater-Setup-<version>.exe`, attached to releases) to update NoteTOO.
It reads `latest.json` from the latest release and installs an update only if that file carries a valid
signature from the NoteTOO release key and the installer's size and SHA-256 match it. Your notes, highlights
and settings are kept.
